Model Architecture

MobileNetV2 Transfer Learning

  • Input Dimensions: 224 × 224 × 3 RGB
  • Base Model: MobileNetV2 pretrained on ImageNet (Inverted Residuals with Linear Bottlenecks)
  • Global Average Pooling: Reduces spatial $7\times 7\times 1280$ activation maps into 1280 feature vectors
  • Regularization: Dropout (0.25) to prevent over-fitting on leaf patterns
  • Output Classifier: 38-neuron Dense layer with Softmax activation

Grad-CAM Gradient Extraction Pipeline

# Gradient-Weighted Class Activation Mapping (Grad-CAM)
with tf.GradientTape() as tape:
    conv_outputs, base_output = intermediate_model(preprocessed_leaf)
    tape.watch(conv_outputs)
    preds = classifier_head(base_output)
    loss = preds[:, predicted_class_idx]

grads = tape.gradient(loss, conv_outputs)
pooled_grads = tf.reduce_mean(grads, axis=(0, 1, 2))
heatmap = tf.reduce_sum(tf.multiply(pooled_grads, conv_outputs[0]), axis=-1)
heatmap = np.maximum(heatmap, 0) / np.max(heatmap)
